# Craftec

A decentralized application platform on [Freenet](https://freenet.org): every
identity owns one authenticated state tree; apps are lenses over it.

| Repo | What |
|---|---|
| [freenet-prolly](https://github.com/craft-ec/freenet-prolly) | prolly tree library |
| [freenet-contracts](https://github.com/craft-ec/freenet-contracts) | Block · Register · Set · Derived contracts |
| [freenet-harness](https://github.com/craft-ec/freenet-harness) | drives a real node; all measurements |
| [craftworks-sdk](https://github.com/craft-ec/craftworks-sdk) | app-facing SDK |
| [craftworks-builder](https://github.com/craft-ec/craftworks-builder) | drag-and-drop app builder |

How we work: [CONTRIBUTING](https://github.com/craft-ec/.github/blob/main/CONTRIBUTING.md).
